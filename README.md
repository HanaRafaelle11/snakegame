# 🐍 Snake Game

Um remake moderno do clássico **Snake Game**, desenvolvido utilizando apenas **HTML5, CSS3 e JavaScript Vanilla**, sem frameworks ou dependências externas.

O projeto foi criado com foco em **boas práticas de desenvolvimento front-end**, organização de código, experiência do usuário e compatibilidade entre dispositivos, servindo como demonstração de habilidades em desenvolvimento web para portfólio profissional.

# ✨ Funcionalidades

### 🎮 Gameplay

* Controle através das teclas direcionais
* Movimento suave e responsivo
* Geração aleatória de comida

* Aumento progressivo da dificuldade
* Colisão com paredes

# 🏗️ Arquitetura do Projeto

O projeto foi desenvolvido em um único arquivo HTML conforme requisito técnico.

```text
index.html
│
├── HTML
│   ├── Estrutura da interface
│   ├── Painel de pontuação
│   ├── Canvas do jogo
│   └── Tela de Game Over
│
├── CSS
│   ├── Layout responsivo
│   ├── Design System
│   ├── Animações
│   └── Tematização
│
└── JavaScript
    ├── Estado do jogo
    ├── Loop principal
    ├── Movimentação
    ├── Detecção de colisões
    ├── Sistema de score
    ├── Controle de velocidade
    ├── Persistência do recorde
    └── Eventos de entrada
```

# ⚙️ Como Executar

## Clonar o repositório

```bash
git clone https://github.com/seu-usuario/snake-game.git
```

## Entrar na pasta

```bash
cd snake-game
```

## Abrir no navegador

Basta abrir:

```bash
index.html
```

Não é necessário:

* Instalar dependências
* Configurar servidor
* Utilizar build tools
* Executar npm install

Este projeto foi desenvolvido como exercício de engenharia front-end e demonstra capacidade de construir aplicações interativas utilizando apenas tecnologias nativas da web.
